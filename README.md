# python-arithmetic-comparison-operators

## 📌 Project Title

Python Arithmetic and Comparison Operators

## 📖 Description

This project demonstrates simple Python operations using Arithmetic Operators and Comparison Operators.

The operations are performed using five different Python data types:

- Integer
- Float
- Complex
- Boolean
- String

The purpose of this project is to understand how different operators work with different data types in Python.

## 🧑‍💻 Data Types Used

1. int
2. float
3. complex
4. bool
5. str

## ➕ Arithmetic Operators

The following arithmetic operators are practiced:

- `+` Addition
- `-` Subtraction
- `*` Multiplication
- `/` Division
- `%` Modulus
- `//` Floor Division

Operations are performed with different data type combinations wherever Python supports them.

## 🔍 Comparison Operators

The following comparison operators are practiced:

- `>` Greater than
- `<` Less than
- `>=` Greater than or equal to
- `<=` Less than or equal to
- `==` Equal to
- `!=` Not equal to
